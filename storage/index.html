About the project

The original implementation uses S3 and IAM, with tests covering file operations and denied requests outside the permitted folder. The web interface extends that work with account-based access.

The front end runs on GitHub Pages. The backend code uses Amazon Cognito for sign-in and an AWS API to authorise file operations. The deployed interface supports sign-in, file uploads, private file lists and downloads.
